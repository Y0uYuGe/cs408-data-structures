# 06 字符串、KMP与Trie：词出现和短语出现是两回事

级别3。代码`engine.py:tokenize/term`、`algorithms.py:kmp_table/kmp_find`、`structures.py:Trie`；测试`test_kmp_table_overlap_empty_unicode`和`test_trie_prefix_removal_shared_path`。

## 存储单位与分词规则

字符串是字符序列。C字符数组通常以`'\0'`标记结束，长度不含终止符；Python str以Unicode码点操作。UTF-8字节长度和字符长度不同，C++示例的KMP返回字节位置，而Python返回字符位置，不能直接用同一整数判断中文位置。

Atlas对Latin连续字母/数字/下划线做小写词，中文连续段生成每个单字与相邻双字。`AVL 数据结构`得到`avl,数,据,结,构,数据,据结,结构`。普通查询`数据结构`要求这些token都出现，可能出现在正文不同位置；`"数据结构"`使用KMP验证连续原文。这是可重现的切分规则，不是自然语言分词器，也没有词干、同义词或停用词功能。

## 从朴素匹配到KMP

朴素匹配在每个起点比较模式，最坏O(nm)。KMP记录模式已匹配前缀可复用的长度，文本指针不回退。模式`ababaca`的前缀表为`[0,0,1,2,3,0,1]`，每一项是该位置前缀的最长相等真前后缀长度。

逐步算到下标4的`ababa`，真前后缀`aba`长度3。下标5字符c与期待b不等，j从3退到table[2]=1；c仍与b不等，再退到table[0]=0；c与a不等，所以table[5]=0。下标6的a与首a相同，table[6]=1。回退必须是`table[j-1]`，不是j减1，才能跳过已证明不可能的状态。

文本`ababababaca`：匹配若干`ababa`后遇到b而模式期待c，退回较短前缀继续比相同文本字符，最终在零起始4找到`ababaca`。建表O(m)，扫描O(n)：虽然有while回退，但j的增加与减少总次数受线性约束。空模式本API返回0；未命中返回-1。

## Trie前缀树

插入tree,trie,trip，前三个字符tr共享路径，之后e/i分开，tri下再分e/p。前缀tri只需沿3条边定位，再枚举两片终止结点。本实现每层children是手写HashMap，枚举用手写Stack，结果字典序。删除trie时先取消终止标记，然后只剪除没有孩子且非词尾的结点，不能把trip共享的tri一起删掉。

Trie查找前缀的定位成本O(m)，返回r个词还要遍历相应子树和构造输出；“Trie查询总是O(m)”忽略了枚举成本。它与AVL不同：Trie按字符分支，AVL按完整键比较。

## 常见错误与练习

错误：把KMP前缀表与教材某种-1起始next表混用；把普通词AND命中当连续短语；把UTF-8字节下标当字符下标；删除前缀词时误删更长词。

练习1：模式aaaa的前缀表？答案`[0,1,2,3]`。练习2：文本abcabc中模式cab首次位置？答案2。

练习3：Trie含树与树形，删除树后prefix树输出？答案仅树形；路径必须保留。练习4：普通查询`tree graph`与短语`"tree graph"`差别？答案前者只要求两个词都出现，后者要求它们按原文顺序连续含空格出现。
