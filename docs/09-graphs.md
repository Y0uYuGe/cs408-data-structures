# 09 图：把“知识相关”与“引用依赖”具体化

级别5。代码`algorithms.py:Graph`、`structures.py:DisjointSet`、`engine.py:graph`。真实CLI支持path和graph算法选择；测试从手算小图与真实文档图两个角度验证。

## 两种图语义

默认共享词图无向：两个文档有至少一个共同token就连边，共同token数s对应权重`max(1,100//s)`，相关越多成本越低。这个教学规则不等同语义相似度或概率。`--directed`使用文档显式links：若文档3链接2，边3→2，权重为文档2正文字符数至少1。此时路径表示沿引用访问的累计阅读成本；关键路径表示在把边解释为活动工期时的结构计算，是否适合实际学习任务需另建模。

图G=(V,E)，有向入度与出度分开，无向度数和=2|E|。简单无向图最多V(V-1)/2边，有向图无自环最多V(V-1)。邻接矩阵存O(V²)，访问一对点是否有边O(1)；邻接表存O(V+E)，扫描某点邻居O(deg(v))。本仓库adj字典是邻接表表达，矩阵只作理论比较。

## BFS、DFS和Dijkstra

例边0–1=7,0–2=1,2–1=1,1–3=1，点4孤立。BFS从0先发现1与2，再经1发现3，输出0→1→3，距离2条边。Dijkstra初始dist0=0、其余∞，松弛出dist1=7,dist2=1；取2后把dist1改2；取1后dist3=3；输出0→2→1→3，总权3。优先队列中旧条目(7,1)留着但弹出时与当前距离比较后跳过。

Dijkstra要求非负边权；本Graph.add明确拒绝负边。首次“入堆”不等于距离已确定，必须取当前最小有效条目。BFS/DFS邻接表理想O(V+E)，这里为确定输出顺序对邻居排序，会增加排序开销。DFS返回可达访问序列，不保证最短路径。不可达path返回空路径与null距离。

## Floyd动态规划

`d[i][j]`表示允许已处理点作中间点的最短距离；第k轮`d[i][j]=min(d[i][j],d[i][k]+d[k][j])`。k必须在最外层，保持阶段语义。时间O(V³)，空间O(V²)；不连通保持∞，CLI转null便于合法JSON。测试将每对点的Floyd距离与Dijkstra比较，而不是仅检查运行不报错。

## 生成森林与并查集

最小生成树连接所有顶点、无环并最小化所选边权，不是在源点到各点路径最短。图不连通时输出最小生成森林，边数V-c。Prim从每个未访问分量起点扩张当前集合最小跨界边；Kruskal按全图边权排序，两端不在同集合则选边并union。并查集通过路径压缩与按秩合并加速，不直接给原图路径。本实现先核验无向对称边，拒绝把有向引用图当成无向MST。

上例忽略孤立4，选0–2、2–1、1–3三条权1边，森林总权3，V=5,c=2，边数3；BFS树可能包含权7边，不保证最小生成树。

## 拓扑与AOE关键路径

拓扑适用于有向无环图DAG；Kahn法统计入度，将0入度点入队，每移除一点就减少出邻居入度。输出不足V说明有环，系统报错。序列可能不唯一，不能把某个合法次序当唯一答案。

AOE把边当活动时长，点当事件。例0→1=2,0→2=3,1→3=4,2→3=1：最早事件时间ve=[0,2,3,6]，工期6；逆拓扑算最迟vl=[0,2,5,6]；边a→b时最早开始e=ve[a]，最迟开始l=vl[b]-w，e=l是关键活动。关键边0→1、1→3。多终点按共同总工期计算，可视为加零权虚拟汇点；关键路径不同于最短路径。

## 练习与常见错误

练习1：6点2个分量森林有几边？答案4。练习2：DAG有两条长度4与6的源汇路径，工期？答案6，若取4就混淆最短与最长约束。练习3：给图加入3→0后拓扑如何？答案报有环，关键路径也不适用。

错误：BFS替代带权最短路；Dijkstra用于负权；MST用于有向图；拓扑遍历未检查输出个数；只沿一条路径找关键活动；认为最小生成树或拓扑一定唯一。
