# 覆盖边界与408范围核对

`topics.json`是机器可检查的定位清单。每条有ID、名称、级别、implemented/theory、代码路径、文档路径、测试定位与notes。`implemented`表示该主题有对应可运行过程，不意味着教材所有变体、所有输入规模或考试所有问法均完成；`theory`意味着这里只提供原理和小例推演。

## 已进入检索系统的主线

动态顺序表/单链表、栈/队列、拉链散列、BST键序/AVL旋转插删、二叉堆、Trie、KMP、Huffman、二分定位、有序倒排双指针集合操作、八排序、图邻接表及BFS/DFS/Dijkstra/Floyd/Prim/Kruskal/并查集/拓扑/AOE。两种倒排表、八排序、查找和图算法可通过真实CLI选择；不是一个不调用的数据结构陈列库。

## 仅理论与纸面训练

双链/循环/静态链表、循环数组队列、稀疏矩阵三元组与快速转置、广义表、一般二叉树遍历与重建、树森林转换、线索二叉树、开放定址与墓碑、B/B+树、外部多路归并/置换选择/败者树、ASL概率模型及复杂度证明。题库中的若干题可检查答案，但没有完整可运行对应变体。数据结构考试并非都必须包装成检索功能，避免强行伪装实现。

## 后续需要补充的能力

在纸上写合法C指针算法、递归证明、复杂度推导、图形构造、难度更高的综合算法设计与时间控制。C和C++示例仅对照核心，不覆盖整套引擎移植。没有逐项核对未来官方大纲，建议以年度大纲为清单标记“已手推/已实现/已限时通过”，不要把存在topics条目当作学会。

## 工程边界

单机、全内存索引与整库快照；没有商用相关性评测、网页解析、词干/词典、权限模型、数据加密、分页磁盘索引、WAL事务或网络服务。恢复测试模拟文件损坏和重启，不模拟真实断电、磁盘/网络文件系统故障。锁等待和PID检测不是分布式锁；两份快照写入之间可能恢复上一版。
