# 07 二叉树、AVL与Huffman

级别3。代码`structures.py:AVLNode/AVLTree/MinHeap`、`algorithms.py:_huffman_tree/huffman_encode`、`engine.py:sizes`；测试含四种旋转、200次插入与200次随机删除的不变量检查，以及空/单符号Huffman。

## 先掌握树的计数与遍历

非空树n个结点恰有n-1条边。二叉树每结点两个孩子指针，共2n，真实边占n-1，所以空指针n+1。度0结点n₀与度2结点n₂满足n₀=n₂+1。高度定义需统一：本实现空树高度0、叶子高度1；有些教材叶子高度0，公式需整体平移。

先序根-左-右，中序左-根-右，后序左-右-根，层序用队列。例如A的左孩子B(B的孩子D,E)、右孩子C，先序A,B,D,E,C；中序D,B,E,A,C；后序D,E,B,C,A；层序A,B,C,D,E。给先序与中序且结点标识唯一，可按根把中序分左右子树递归重建；只有先序与后序一般不能唯一确定，单孩子在左或右无法区分。

完全二叉树数组零起始时左孩子2i+1、右孩子2i+2、父结点(i-1)//2。MinHeap使用这一存储，任意树不能套用“前n个数组槽全占”假设。

## AVL维护正文长度索引

普通BST左键小、右键大；顺序插入可能退化成链。AVL进一步要求左右高度差绝对值≤1，插删后向根回溯刷新高度并旋转。本系统键为`(正文字符数,docID)`，避免多篇长度相同覆盖彼此；range闭区间按长度返回记录。

LL插入30,20,10：30左子过高且20左边高，对30右旋，20成为根、10左、30右。RR镜像左旋。LR插入30,10,20：先对10左旋，再对30右旋。RL插入10,30,20：先对30右旋，再对10左旋。旋转改变链接但保留中序顺序，这是查找正确性的核心。

删有两孩子结点时用右子树最小键（中序后继）替换，再删后继；删后高度下降可能让多个祖先失衡，因此不能只调整一次。测试每次插删后检查完整BST顺序、高度与平衡；更新正文实际先delete旧长度键再put新键。

## Huffman编码与堆

权重2,3,7：从最小堆取2和3合并成5，再取5和7合并成12。权重2/3叶深2，7叶深1，WPL=`2×2+3×2+7×1=17`，等于合并权重5+12。每次合并最小两棵树形成最优前缀码树，叶子代表符号，任一叶码不是另一叶码的前缀。

归档对UTF-8字节而非中文字符编码，最多256种符号。单一符号约定码0而不是空码，以便逐个解码；空输入单独处理。归档还保存频数、有效位数和checksum，所以小文件可能因元信息反而变大。生成一棵Huffman树约O(s log s)，输出位打包O(encoded_bits)。

## 理论项与练习

树/森林可用左孩子右兄弟法转二叉树：第一个孩子放left，下一个兄弟放right；right不再代表原树的孩子。线索二叉树利用空指针存遍历前驱/后继，必须有tag区分真孩子与线索。本仓库只讲解这两个变体，没有完整实现。

练习1：7结点二叉树空指针多少？答案8。练习2：先序A,B,C与后序C,B,A能否唯一确定？答案不能，链上左右孩子选择可能不同。

练习3：权重1,1,2,4的WPL？答案先1+1=2，再2+2=4，再4+4=8，总14。练习4：AVL插入30,10,20的中序与根？答案中序10,20,30，根20，执行LR旋转。
