# 本机验证记录

记录日期：2026-10-15。本机环境：Windows，Python 3.13.5。仓库运行目标：Python≥3.11，标准库，无运行依赖。

执行：`python -m unittest discover -s tests -v`。本机最新结果：**48个unittest测试全部通过，耗时约3.3秒**。其中若干测试用subTest遍历多组输入，48是测试方法数，不把每个循环案例夸大计数。

## 已实际验证

- 独立子进程执行全部公共子命令：init、add、update、delete、index、search、suggest、range、show、list、path、graph、export、import、check、repair、tokenize、practice、assess。
- 数据跨进程保存，关闭对象后重启查询；更新/删除清除旧词、Trie和长度索引，删除清除入站引用。
- 两种真实倒排后端、八种排序对相同真实检索结果输出一致；结构/算法用空、重复、有序、逆序、负数、Unicode等边界输入验证。
- 六个同时启动的独立进程添加文档，ID为1–6且全部文档保存；锁排他与持锁子进程异常终止后的自动释放。
- 主快照损坏后从备份恢复最新完整文档；双副本损坏报错；有效副本revision不同时选择最新；忽略未提交.tmp。
- 注入备份写入失败，证明主快照已提交的新文档可重启恢复，同时说明报错不一定意味着完全未提交。
- 目录upsert按绝对路径保留ID，UTF-8解码失败阻止本轮修改；Huffman空/单符号/全256字节/中文往返，损坏与解压限额拒绝。
- 200个不同键随机顺序AVL插入及删除，每次验证完整键序、高度、平衡；散列碰撞、rehash和None值；KMP重叠与Unicode；图最短路、生成森林、拓扑环和关键路径。
- check检测倒排、词频和长度索引损坏。66个知识点路径/符号/测试定位可解析；48原创题全部正确答案能得100，六级和所有诊断分层可检查。
