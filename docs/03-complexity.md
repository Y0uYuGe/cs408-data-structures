# 03 ADT、不变量与复杂度

级别1。对应`structures.py:DynamicArray/HashMap/AVLTree`、`algorithms.py:sort_values`，验证见`tests/test_structures.py`。学会复杂度不是背一张表，而是明确输入规模、基本操作、最坏/平均/均摊模型。

## ADT与实现

线性表ADT描述有序元素及插入、删除、访问的语义。顺序表和链表是两种物理实现。栈ADT约束只能在一端插删，队列约束先入先出。本仓库Stack使用DynamicArray，Queue使用LinkedList；把实现换成循环数组，并不会改变队列的FIFO语义。

不变量是操作前后必须成立的条件，例如动态数组`0≤size≤capacity`，链表空时head/tail均为空，倒排表有序且ID唯一，AVL任意结点左右高度差不超过1。正确性证明通常分初始化成立、每次操作保持、终止后得到结果三步。

## 时间分析的基本推演

`for i in range(n)`执行n次常数操作，Θ(n)。两层各n次是Θ(n²)。若内层从i开始到n-1，总次数`n+(n-1)+...+1=n(n+1)/2`仍为Θ(n²)。`i*=2`达到n需约log₂n步。折半查找每次把剩余区间减半，时间O(log n)，而不是因为代码只有一个while就O(n)。

O表示渐进上界，Ω表示下界，Θ表示同阶界。`3n²+8n+2`为Θ(n²)，也属于O(n³)，但后者不紧。空间要说明是否计输入与输出；排序返回新列表时至少有O(n)输出空间，不能直接套“原地堆排序O(1)”到本仓库的MinHeap排序。

## 均摊不是平均概率

动态数组从容量4倍增，某次append会搬移全部n个元素，最坏O(n)。连续n次append的总搬移不超过`4+8+16+...<2n`，加n次写入，总O(n)，所以均摊O(1)。均摊结论无需假设输入随机。顺序表头插每次都移n个元素，不因容量倍增就变成O(1)。

散列期望O(1)依赖散列分布和负载控制，攻击性碰撞可退化O(n)；AVL用旋转把树高限制O(log n)，保证键查找/插删的最坏界。哈希计算本身要遍历字符串长度m，严格成本应写O(m+桶链长度)。

## 系统整体成本

设N篇文档，总字符数C，独立词数V，总“词—文档”关系P。启动要分词并重建索引；写操作即使只改一篇，序列化整库也有O(C)量级开销。共享词图按文档对比较，最坏至少O(N²)对；Floyd为O(N³)。因此单个AVL操作快，不代表整个写入命令O(log N)。

## 练习与答案

1. `i=1; while i<n: i*=3`时间？答案Θ(log n)，底数改变仅影响常数。
2. 二分递归各处理一半并线性合并，`T(n)=2T(n/2)+Θ(n)`？答案Θ(n log n)，每层总Θ(n)，约log n层。
3. 递归单链表求长的额外栈空间？答案O(n)，即使每层只保存常数信息。
4. 一个查找平均2次比较是否一定比平均3次更快？答案不一定，还需键比较成本、缓存、分配和I/O等常数；ASL只衡量规定的比较模型。
